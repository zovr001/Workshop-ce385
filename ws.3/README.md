ข้อที่ 1 — ระบบตรวจทะเบียน (Error-first Callback)
สาระสำคัญ: ต้องเช็ค err ก่อนเสมอ ถ้าเจอข้อผิดพลาดให้ใส่ return callback(err) เพื่อหยุดการทำงานทันที ป้องกันไม่ให้โปรแกรมฝืนทำงานต่อจน crash

ข้อที่ 2 — แปลง Callback เป็น Promise
สาระสำคัญ: หากสำเร็จส่งข้อมูลผ่าน resolve() หากเกิดปัญหาส่งผ่าน reject() ช่วยให้เขียนโค้ดต่อกันเป็นสาย (Promise Chain) ได้สะอาดขึ้น และมีฟังก์ชัน promisify แปลงโค้ดเก่าเป็น Promise อัตโนมัติ

ข้อที่ 3 — async/await และลำดับ vs ขนาน
สาระสำคัญ:
แบบลำดับ (for...of + await): รอทำทีละอัน (ใช้เวลา ~900ms)
แบบขนาน (Promise.all): สั่งทำพร้อมกันหมด (ใช้เวลา ~300ms เร็วขึ้น 3 เท่า)
การจัดการ Error: ใช้ try-catch ดักจับ reject ได้ทันที

ข้อที่ 4 — เลือก Combinator ให้ถูกงาน
สาระสำคัญ:
Promise.all: ต้องสำเร็จ ครบทุกตัว ถึงจะไปต่อ (พังอันเดียว = พังทั้งหมด)
Promise.allSettled: ทำจน จบทุกตัว ไม่สนใจว่าสำเร็จหรือล้มเหลว (เก็บผลลัพธ์ทั้งหมด)
Promise.any: เอาแค่ตัวแรกที่ สำเร็จ (มองข้ามตัวที่ล้มเหลว)
Promise.race: เอาตัวที่ เสร็จเร็วที่สุด เข้าเส้นชัยก่อน (วัดความเร็ว)
